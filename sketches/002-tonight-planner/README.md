## Variant: Tonight Planner

### Design stance
오늘 밤의 수면 계획을 한 장에서 훑고 필요한 항목만 바텀시트로 수정하는 실용적 흐름.

### Key choices
- Layout: 홈 요약 카드 + 항목별 편집 시트
- Typography: 계획 정보의 빠른 스캔을 우선
- Color: 따뜻한 종이색 바탕과 밤 남색 헤더
- Interaction: 기상/취침 선택값을 편집하고 홈 요약 시안에 즉시 반영
- Scope: 상호작용 시안일 뿐 저장·권한·알람 예약·플레이리스트 저장은 수행하지 않음

### Trade-offs
- Strong at: 매일 계획 수정, 플레이리스트 관리, 한 화면 요약
- Weak at: 첫 사용자에게는 기능 설명이 부족할 수 있음

### Best for
- 튜토리얼 완료 후 일상적인 Warmly 홈
