## Variant: Calm Sunrise

### Design stance
처음 설치한 사용자를 한 단계씩 안내하는 감성적이고 여백이 큰 튜토리얼 중심 흐름.

### Key choices
- Layout: 화면마다 하나의 결정만 제시하는 선형 단계
- Typography: 큰 기상 시각과 짧은 한국어 문장
- Color: 밤 남색에서 살구빛 아침으로 이어지는 그라데이션
- Interaction: 다음/이전, 기상 시각 변경, 재계산된 취침 추천·직접 설정 선택, 선택값의 확인·홈 시안 전파
- Scope: 상호작용 시안일 뿐 저장·권한·알람 예약·음악 재생은 수행하지 않음

### Trade-offs
- Strong at: 첫 설정의 이해도, 감정적 첫인상, 낮은 인지 부하
- Weak at: 설정을 자주 바꾸는 사용자는 단계 이동이 길게 느껴질 수 있음

### Best for
- Warmly 첫 설치 튜토리얼과 최초 수면 계획 생성
