## 확인된 패턴과 Warmly 해석

| 확인된 패턴 | Warmly에서의 선택 |
|---|---|
| 수면 일정은 취침·기상을 한 묶음으로 보여준다 | 여러 알람 목록 대신 단일 수면 계획 카드 |
| 알람 시각은 화면에서 가장 크고 빠르게 읽힌다 | 홈과 설정 모두 기상 시각을 최상위 정보로 배치 |
| 플레이리스트는 이름이 있는 컨테이너이고 편집 화면에서 순서를 바꾼다 | `기상 플레이리스트`에 이름, 곡 수, 정렬·삭제·미리 듣기 제공 |
| 음악 추가는 라이브러리/파일 선택에서 시작한다 | Android 문서 선택기로 여러 로컬 곡을 가져온 뒤 앱 저장소에 복사 |
| 권한은 기능이 필요한 순간에 요청할 수 있다 | 첫 화면에서 일괄 요청하지 않고 최종 준비 단계에서 이유와 상태 표시 |
| 반복 일정과 다음 기상만의 예외는 구분될 수 있다 | `오늘만 변경`은 반복 계획을 암묵적으로 덮어쓰지 않음 |
| 실제 알람 실패 조건은 여러 시스템 상태에 걸쳐 있다 | 알림·정확 알람·전체 화면·음량·진동·백그라운드 상태를 하나의 준비 점검으로 표시 |
| 일부 알람 앱은 미션·추적·구독 기능을 전면에 둔다 | 1단계에서는 미션, 수면 자동 측정, 계정, 구독을 제외 |

## UX 결정

### 첫 설치: Calm Sunrise

한 화면에 하나의 결정만 둔다.

1. 소개
2. 기상 시각
3. 추천 취침 시각 3개 또는 직접 설정
4. 기본 음악 또는 내 플레이리스트
5. 권한과 준비 상태
6. 짧은 시험 알람으로 실제 동작 확인
7. 첫 계획 저장·예약

어두운 밤색에서 살구빛 아침으로 이어지는 배경, 큰 문장, 하단의 단일 주요 버튼을 사용한다.

### 매일 쓰는 홈: Tonight Planner

설치 후에는 튜토리얼을 반복하지 않는다. 한 화면에 다음만 보여준다.

- 내일 기상 시각
- 오늘 취침 시각
- 부드러운 기상 시작 시각
- 선택한 플레이리스트
- `오늘 계획 시작` 또는 준비 상태

각 항목은 전체 편집 화면으로 이동하지 않고 바텀시트에서 바꾼다. 하단 탭은 `오늘 / 음악 / 설정` 세 개만 둔다.

반복 계획을 도입할 때는 `오늘만 변경`과 `계속 적용`을 명확히 분리한다. 홈의 준비 상태는 `준비됨 / 확인 필요 / 선택 사항`으로 표시하고, 문제가 있는 행은 바로 해결 화면으로 연결한다.

## 플레이리스트 최소 흐름

```text
음악 탭
→ 내 플레이리스트 만들기
→ 이름 입력
→ 휴대폰에서 여러 곡 가져오기
→ 곡 목록에서 드래그 정렬·삭제·미리 듣기
→ 기상에 사용
```

- 빈 상태에는 설명보다 `곡 가져오기` 행동을 먼저 보여준다.
- 한 곡이 실패하면 다음 곡, 모두 실패하면 기본 알람음으로 전환한다.
- 여러 파일 가져오기는 선택 표시와 `N곡 추가` 완료 버튼을 사용한다. 성공한 곡은 먼저 반영하고 중복·미지원·권한 실패를 파일별로 보고한다.
- 재생할 수 없는 곡은 자동으로 사라지지 않는다. 원래 순서에 비활성 행으로 남기고 `파일 없음`과 `찾기 / 교체 / 재생목록에서 제거`를 제공한다.
- `재생목록에서 제거`와 `오디오 파일 삭제`는 서로 다른 행위로 명시한다.
- 편집 상태에서는 드래그 손잡이를 항상 보이고, 제거 후에는 짧은 실행 취소를 제공한다.
- 스트리밍 서비스 연결처럼 보이는 UI를 사용하지 않는다.

## 피할 것

- 다중 알람 목록을 첫 화면으로 사용
- 수면 주기를 정확한 의학 공식이나 개운함 보장처럼 표현
- 시작 시 알림·정확 알람·전체 화면 권한을 연속으로 요청
- 편집 화면에서 모든 램프 수치를 한꺼번에 노출
- 플레이리스트에 소셜·추천·공유 기능을 섞음
- `준비 완료`라고 표시하면서 필수 권한이나 예약이 빠진 상태
- 넓거나 설명되지 않은 스마트 기상 구간으로 최종 기상 시각을 모호하게 만드는 것
