# GentleWake modification notice

GentleWake is based on Lux Alarm 2.4.1 by Daniel Salmun, upstream commit
`147ea5c4ce4ea416a1d02975754cc12496e73433`.

This branch was modified in 2026 to add a Korean gentle-wake preview, the
platform-independent wake ramp, wake-profile settings, and app-managed local
audio import with fallback behavior. The scheduled gradual wake runtime is not
implemented by this preview slice.
